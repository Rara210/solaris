# Système solaire 3D

Explorateur interactif du système solaire (Three.js). Aucune étape de build.

## Mise en ligne sur GitHub Pages
1. Créez un dépôt GitHub, puis envoyez-y `index.html`, `style.css`, `main.js` et `README.md` à la racine.
2. Dépôt → **Settings → Pages** → Source : *Deploy from a branch* → branche `main`, dossier `/ (root)`.
3. Le site est disponible après une minute sur `https://VOTRE-NOM.github.io/NOM-DU-DEPOT/`.

## Commandes
Clic sur un astre · glisser/molette · ← → pour changer d'astre · Échap : vue d'ensemble · Espace : pause.
